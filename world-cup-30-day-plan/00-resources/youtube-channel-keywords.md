## ✅ ENTRY TIPS
1. Paste one line → Enter → next line. YouTube turns each into its own tag chip.
2. Watch the character counter — stop adding optional extras when you near 500.
3. Order doesn't matter to YouTube; the topics just need to be present.
4. Revisit every ~3 months: if a channel pivots (e.g. more World Cup content), swap dead phrases for live ones.
