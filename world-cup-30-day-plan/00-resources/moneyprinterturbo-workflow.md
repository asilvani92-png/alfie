# ⚙️ MONEYPRINTERTURBO PRODUCTION PIPELINE (MacBook)
### The exact repeatable workflow for every video in this plan

---

## 🧰 ONE-TIME SETUP (Day 0 / Day 1)

1. **Install & configure MoneyPrinterTurbo** (browser-based UI on your Mac).
2. **Voice:** ElevenLabs — deep male, "documentary" delivery. Save as preset `WC-DOC`.
   - Settings: stability ~50–60%, style/exaggeration moderate. Slightly slower pace for drama; bump pace +10% for Shorts.
3. **Stock sources:** connect Pexels + Pixabay API keys.
4. **B-roll keyword bank** (save as a note, paste per project):
   - Core: `stadium crowd`, `soccer celebration`, `world cup trophy`, `football stadium night`, `fans cheering`, `soccer training`
   - Dark history: `empty stadium`, `rain stadium`, `newspaper printing`, `courtroom`, `city night`, `documents desk`
   - Messi/legend: `argentina flag`, `buenos aires`, `soccer silhouette sunset`, `kid playing football street`, `confetti celebration`
   - Travel/cities: `los angeles skyline`, `mexico city aerial`, `toronto skyline`, `airport travel`, `road trip`
   - Science: `brain scan`, `slow motion ball`, `goalkeeper dive`, `heartbeat monitor`, `chalkboard diagram`
5. **Music presets:** Cinematic/Epic (dark topics), Emotional Piano (Messi/underdogs), Upbeat Electronic (explainers/travel).
6. **Export presets:** 1080p 16:9 (YouTube), 1080×1920 9:16 (Shorts/TikTok/Reels).

---

## 🎬 LONG-FORM DOCUMENTARY PIPELINE (~3–4 hours, split over 2 days)

```
DAY A — SCRIPT (60–90 min)
1. Research: 30 min of sources, save quotes/facts to a notes file.
2. Script with AI assist: 1,100–1,300 words (≈ 7.5–9 min at documentary pace).
   Structure (non-negotiable):
   ├─ 0:00–0:25  COLD OPEN — most shocking fact, no intro
   ├─ 0:25–1:00  PROMISE — "by the end you'll know…" + setup
   ├─ 1:00–6:30  3 ACTS — each ends with an open loop re-hook
   ├─ 6:30–7:30  PAYOFF — answer the cold open's question
   └─ 7:30–8:30  DEBATE CTA — pose a question + subscribe line
3. Mark 3–5 segments in the script as [SHORT] — these become clips.

DAY B — PRODUCTION (90–120 min)
4. Paste script → MPT script field.
5. Voice: WC-DOC preset. Style: "documentary".
6. Footage keywords: 6–10 from the bank, matched to each act.
7. Music: per topic preset. Volume: voice -0 dB, music -18 to -22 dB.
8. Subtitles: ON, high-contrast (white + black outline), max 2 lines.
9. Render 16:9 full video → watch ONCE at 1.5× → fix any bad clip matches.
10. Render the [SHORT] segments at 9:16 (or auto-clip 3–5 shorts).
11. Thumbnail: 1280×720, one object + ≤4 words (Canva, dark + gold).
12. Upload: title (≤60 chars), description with chapters + keywords, end screen.
```

## ⚡ SHORT-FORM PIPELINE (30–45 min per short)

```
1. Script: 110–150 words (≈ 45–59 seconds).
   Structure: HOOK (1 line) → STORY/PAYOFF (3–5 beats) → LOOP/CTA (1 line).
2. MPT: 9:16, fast-cut style, 2–4 footage keywords, captions LARGE.
3. Export once → post natively 3×: TikTok, Shorts, Reels (no watermarks).
4. Per-platform captions from hashtag-bank stacks.
5. Pin a question comment immediately.
```

## 🚨 REACTIVE CLIP PIPELINE (target: < 90 min from event to live)

```
1. Event happens → 15 min: gather 3 facts + the emotional angle.
2. 15 min: write 120–150 word script using a Section F hook (hook-library).
3. 30 min: MPT render, urgent pacing, crowd/stadium B-roll.
4. 15 min: post TikTok first, then Shorts, then Reels. Title includes the
   player/team name (search traffic spikes hardest in hours 2–12).
```

---

## ✅ QUALITY CHECKLIST (every render, 60 seconds)
- [ ] Hook spoken + on screen in first 1.5s (shorts) / 5s (long)
- [ ] No clip repeats within 30 seconds of itself
- [ ] Subtitles synced, no typos in the first 10 seconds
- [ ] Music ducked under voice
- [ ] One CTA only
- [ ] Title contains the search keyword
- [ ] Vertical exports are true 9:16 (no letterboxing)
