# 🎯 USAGE RULES

1. **Link-in-bio:** TikTok/IG/X bios above end with "👇 / ↓" — always have the Linktree/Beacons link directly below (latest doc + free Survival Guide from Day 27).
2. **Display names:** pair every handle with the spaced display name — "The Penalty Files", "The Cursed Pitch", etc. The display name is searchable on TikTok/IG, so it doubles your discoverability.
3. **Keep the first 100 characters of the YouTube description keyword-rich** — that's the snippet YouTube shows in search results.
4. **Update cadence lines honestly:** if you're not posting daily on FearTheWhistle yet, change "Daily" to "New verdicts every match week" until you are. Broken promises in bios cost follows.
5. **Localize later:** when the Mexican audience share grows (Jiménez project), add one Spanish line to the IG bio of the relevant channel: `🇲🇽 Historias del fútbol que nunca te contaron.`
6. **Consistency check:** same emoji "icon" leads each brand everywhere (🗂️ Files / 🕯️ Cursed / 🥹+⚽ TwelveYard / 📣 Whistle) — it becomes part of the brand recognition.
