# 🎨 BRAND IMAGE PROMPT PACK
## Copy-paste AI prompts for logos (PFPs) + banners — every channel name + backups
**Works in:** Midjourney, DALL·E/ChatGPT, Ideogram (best for text), Leonardo, Canva AI, Bing Image Creator.

---

## ⚠️ READ FIRST — 5 rules that make or break AI brand images

1. **Generate the artwork WITHOUT text, add text yourself in Canva.** AI mangles letters; clean type added afterwards always beats generated type. (Exception: **Ideogram** handles short text well — text-inclusive prompt variants are provided below.)
2. **PFPs display as tiny circles.** One bold symbol, centered, ~70% of frame, instantly readable at 36px. No scenes, no detail clutter.
3. **One prompt run ≠ done.** Generate 4+ variations, pick, then ask for refinements ("same design, thicker lines, more contrast").
4. **Lock ONE palette across all brands** so your network feels related: **near-black (#0E0E10) + molten gold (#D4A017) + off-white accents** — the football-drama aesthetic from your plan. Each sub-brand gets ONE accent twist (listed per name).
5. **Banner safe zones:** YouTube banners are 2560×1440 but only the central **1546×423** shows on all devices — keep the logo/title there. Generate 16:9 and crop.

---

## 🧩 THE MASTER TEMPLATE (how every prompt below is built)

```
[FORMAT] for a faceless football documentary brand called "[NAME]".
Subject: [ONE ICONIC SYMBOL — the brand's visual hook].
Style: minimalist vector logo mark, flat design with subtle depth, cinematic
sports-noir mood, premium documentary branding (think Netflix sports doc
meets classic football crest).
Palette: matte near-black background (#0E0E10), molten gold (#D4A017)
primary, [ACCENT] highlight, off-white details. High contrast.
Composition: symbol perfectly centered, fills 70% of frame, bold silhouette
readable at tiny sizes, generous negative space, circular-crop friendly.
Lighting: single dramatic rim light, slight stadium-floodlight glow.
NO TEXT, no letters, no words, no watermark, no photorealistic faces,
no clutter, no gradients-rainbow, no busy background.
```

# 3️⃣ BANNER PROMPTS (YouTube 2560×1440 / X header / IG highlight covers)

### Universal banner template — swap [SYMBOL SCENE] per brand
```
Wide cinematic YouTube channel banner, 16:9, for a faceless football
documentary brand. Scene: [SYMBOL SCENE]. Style: premium sports-noir,
minimalist with atmospheric depth, dark documentary mood like a streaming
sports-doc key art. Palette: matte near-black (#0E0E10) dominant, molten
gold (#D4A017) focal glow, [ACCENT] secondary, off-white fine details.
Composition: all focal elements concentrated in the CENTRAL horizontal band
(middle 60% width, middle 30% height) with calm dark space above and below —
edges must stay simple and uncluttered. Lighting: stadium floodlight haze,
volumetric beams, cinematic contrast. NO TEXT, no letters, no watermark,
no faces, no logos of real clubs.
```

**[SYMBOL SCENE] per brand:**
- **ThePenaltyFiles:** *"a long dark investigation desk stretching across frame, scattered case-file folders and a single glowing football under a desk lamp, faint stadium silhouette in the far background haze"*
- **TheCursedPitch:** *"an empty haunted stadium at midnight, mist rolling over the pitch, center circle glowing faint gold, one floodlight flickering"*
- **TwelveYardStories:** *"the loneliest walk in football — a penalty spot under a single floodlight beam in a vast dark empty stadium, ball waiting on the spot, goal glowing faintly in the distance"*
- **FearTheWhistle:** *"a colossal referee's whistle suspended above a dark stadium like a judge's gavel, gold sound-waves rippling across the crowd silhouettes below"*
- **Backups:** reuse each PFP subject, widened into a stadium environment.

### After generating, add text in Canva (90 seconds):
1. Drop the image into a 2560×1440 frame
2. Channel name in **bold condensed sans-serif** (Bebas Neue / Archivo Black), gold or off-white, dead-center
3. One-line tagline under it, small: *"The stories football tried to forget."*
4. Keep ALL text inside the central 1546×423 safe zone
5. Export → also crop a 1500×500 version for X

# 6️⃣ THE REFINEMENT LOOP (after first generation)
- "Same design, simplify further — fewer details, thicker bolder shapes."
- "Increase contrast between the gold symbol and the black background."
- "Make it read clearly when shrunk to 36 pixels."
- "Flat vector style, remove the 3D shading."
- "Give me a monochrome white-on-transparent version for a video watermark."

**Final consistency check:** put all 4 brand PFPs side by side — same black, same gold, different symbol + accent. If one looks like a different family, regenerate it with the master palette line pasted verbatim.
